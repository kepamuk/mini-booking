# Mini Booking

Бронирование одной переговорной комнаты по часовым слотам. Расписание доступно каждый день с 09:00 до 18:00, включая выходные.

Стек: Laravel 12, Vue 3 (`<script setup>`), TypeScript, PrimeVue 4, SQLite. Frontend находится в `resources/js` и собирается через Vite; Laravel отдаёт страницу и JSON API.

## Требования

- PHP 8.2+ с расширениями `pdo_sqlite`, `sqlite3`, `mbstring`, `openssl`, `fileinfo`, `xml`, `dom`, `curl`.
- Composer 2.
- Node.js 22.12+ и npm.

## Установка и запуск

```bash
git clone https://github.com/kepamuk/mini-booking.git
cd mini-booking
composer install
php -r "copy('.env.example', '.env');"
php artisan key:generate
php -r "file_exists('database/database.sqlite') || touch('database/database.sqlite');"
php artisan migrate --seed
npm ci
npm run build
php artisan serve
```

Приложение откроется на [http://127.0.0.1:8000](http://127.0.0.1:8000). После сборки frontend обслуживается Laravel, отдельный процесс Vite не требуется.

Для разработки запустите в двух терминалах:

```bash
# Laravel
php artisan serve

# Vue с HMR, во втором терминале
npm run dev
```

Обе части также можно запустить командой `composer dev`. Страницу открывайте на порту 8000.

## Настройки и расписание

Основные параметры `.env`:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `APP_TIMEZONE` | `Europe/Moscow` | Часовой пояс расписания |
| `APP_URL` | `http://127.0.0.1:8000` | Адрес приложения |
| `DB_CONNECTION` | `sqlite` | Подключение к БД |
| `DB_DATABASE` | не задана | Используется `database/database.sqlite`; для другого файла укажите абсолютный путь |

Команды для миграций и заполнения базы:

```bash
php artisan migrate
php artisan db:seed
```

`SlotSeeder` создаёт 63 слота: 7 календарных дней начиная с сегодняшнего, по 9 слотов в день. Прошедшие часы текущего дня тоже создаются. Повторный запуск сохраняет существующие ID и бронирования; при запуске в другой день добавляются недостающие слоты. Старые данные не удаляются.

Начало и конец слота хранятся как Unix timestamp в секундах. Seeder использует календарь из `config('app.timezone')`, API возвращает ISO 8601 со смещением и название пояса в `meta.timezone`. Frontend показывает даты и время в этом поясе. Слот считается прошедшим при `starts_at <= now()->timestamp`; окончательная проверка выполняется на сервере.

## API

| Метод | URL | Результат |
| --- | --- | --- |
| GET | `/api/slots` | Слоты по возрастанию начала: ID, начало, конец, статус и ID бронирования. Имя и email не возвращаются |
| POST | `/api/bookings` | Принимает `slot_id`, `customer_name`, `customer_email`. Возвращает `201` и `{"id": ...}` |
| DELETE | `/api/bookings/{id}` | Отменяет бронь, возвращает `204`, в том числе при повторной отмене |

Статусы слота: `available`, `booked`, `past`. Ошибки валидации возвращаются с кодом `422` и объектом `errors` по полям. Занятый или прошедший слот возвращает `409` с сообщением о причине конфликта.

Уникальный индекс `bookings.slot_id` гарантирует одну активную бронь на слот. Создание выполняется одним атомарным `INSERT`; нарушение уникальности преобразуется в `409`. При отмене запись удаляется, освобождая слот. Для SQLite настроены WAL и ожидание блокировки до 5 секунд. У слотов также есть уникальный индекс времени начала и внешний ключ из бронирований.

## Проверка

```bash
php artisan test
npm run build
```

PHPUnit работает с отдельной SQLite-базой `:memory:`. Тесты проверяют успешное бронирование, конфликт повторной брони, ограничение UNIQUE, отмену и повторное создание, валидацию, границу времени, приватность ответа и работу Seeder. GitHub Actions запускает тесты и сборку на PHP 8.2 / Node 22.

Вручную: выберите будущую дату, забронируйте свободный слот и отмените его через подтверждение. Для проверки конфликта откройте форму одного слота в двух вкладках и отправьте обе. Для сетевой ошибки включите Offline в DevTools: форма сохраняет данные и позволяет повторить запрос после восстановления подключения.

Авторизация, управление комнатами, история отмен и автоматическое продление расписания не входят в объём. В демо отмена по известному ID доступна без авторизации.
